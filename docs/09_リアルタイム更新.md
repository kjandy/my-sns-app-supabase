# 第9回 リアルタイム更新（Realtime）

> 開始タグ：`lesson08-step2` → 到達タグ：`lesson09-step3`

## この回のゴール

- 他の人の投稿・いいね・コメントが、**再読み込みしなくても** 画面に反映される
- Realtime で届くのは「変わった1行の差分」だけであることを理解し、必要な情報を読み直せる
- 購読（subscribe）と解除（unsubscribe）を `useEffect` で正しく扱える

## 講義

### 1. しくみ

```text
① 佐藤さんが投稿する（INSERT）
        │
        ▼
② Supabase：posts は「配信リスト（publication）」に入っている → 変更を配信
        │   ※ RLS で「その人が読める行」の変更だけが届く
        ▼
③ 安堂さんのブラウザ：subscribeTimeline() の .on('postgres_changes', …) が呼ばれる
        │   payload.new = { id, user_id, content, created_at }  ← 名前・件数は入っていない
        ▼
④ timeline_posts ビューからその1件を読み直して、一覧の先頭に足す
```

### 2. 届く中身

| イベント | `payload.new` | `payload.old` |
|---|---|---|
| INSERT | 追加された行 | ― |
| DELETE | ― | **主キーだけ**（`id`。`post_reactions` なら `post_id`・`user_id`・`kind`）【確認済】 |

- `filter: 'post_id=eq.xxx'` で「この投稿へのコメントだけ」に絞れる。ただし **DELETE には filter が使えない**【確認済】ので、届いた id が表示中のものか自分で確かめる

### 3. 購読は「画面を開いている間だけ」

```js
useEffect(() => {
  if (!user) return;
  const unsubscribe = subscribeTimeline(); // 購読を始める
  return () => unsubscribe();              // 画面を離れたら解除（必ず）
}, [user, subscribeTimeline]);
```

解除を忘れると、ページを行き来するたびに購読が増え、**同じ投稿が何度も足される** 原因になります。

## 確認クイズ

1. Realtime で届いた投稿に名前が入っていないのはなぜ？ どうする？ → 届くのは `posts` の1行だけだから。ビューからその1件を読み直す
2. `useEffect` のクリーンアップで購読を解除しないと？ → ページを移動するたびに購読が増え、同じ通知を何度も受け取る

## よくあるつまずき

| 症状 | 原因 | 対処 |
|---|---|---|
| 何も届かない | publication に入れていない | Step 1 の SQL を実行 |
| 同じ投稿が2つ並ぶ | 重複チェックが無い／購読の解除漏れ | `_prependPost` とクリーンアップを確認 |
| 削除が反映されない | DELETE に filter を付けた | DELETE は filter なしで受け取り、自分で確かめる |
| しばらくすると届かなくなる | 無料プランの同時接続数などの制限【未確認】 | 再読み込みして購読し直す |
