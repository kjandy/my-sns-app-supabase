# 第12回 DM のリアルタイム・既読・未読バッジ

> 開始タグ：`lesson11-step2` → 到達タグ：`lesson12-step3`（完成）

## この回のゴール

- 開いているメッセージ画面に、相手のメッセージがすぐ届く
- メッセージ画面を開いたら **既読** にする
- 未読があると、ヘッダー・下部ナビ・会話一覧に **未読バッジ（青い点）** を出す

## 講義：購読する場所を決める

| 購読 | どこで | いつまで |
|---|---|---|
| `subscribeMessages(会話)` | メッセージ画面（`DMThreadClient`） | その画面を開いている間 |
| `subscribeConversations()` | **`ClientLayout`（アプリ全体で1か所）** | ログインしている間ずっと |

- 未読バッジはヘッダーにも下部ナビにも会話一覧にも出ますが、購読は **1か所だけ**。2か所で購読すると、片方の画面を離れたときに解除されてしまうため
- 3つの場所は、同じストアの値（`selectHasUnread`）を見るだけ

```text
相手がメッセージを送る
  → messages に INSERT  → 開いているメッセージ画面に追加 → 既読にする（mark_conversation_read）
  → トリガーが conversations を UPDATE → subscribeConversations が会話一覧を読み直す → バッジ更新
```
