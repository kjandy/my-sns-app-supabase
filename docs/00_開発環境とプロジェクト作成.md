## Step 2：shadcn/ui・色・日本語フォントを設定する

### 2-1. shadcn/ui を入れる

shadcn/ui は「部品のソースコードを自分のプロジェクトにコピーして使う」方式の部品集です。`components/ui/` に入ったファイルは、自分で自由に書き換えられます。

```bash
npx shadcn@latest init
```

- スタイルを聞かれたら **radix-nova**、ベースカラーは **neutral** を選びます【未確認：CLI の質問の文面】
- 終わると `components.json` と `lib/utils.js` が作られ、`app/globals.css` に色の変数が追加されます

続けて、この講座で使う部品をまとめて追加します。

```bash
npx shadcn@latest add button card input label dialog sheet avatar alert
```

> 🆘 **うまくいかないとき**：学校のネットワークなどで shadcn のサーバーにつながらない場合は、完成形のリポジトリから部品だけ取り出せます。

### 解説：`cacheComponents: false` にする理由

create-next-app の雛形では `cacheComponents: true`（Cache Components という新しい仕組み）が有効になっています。
これが有効だと、Cookie（＝ログイン情報）を読むページを、すべて `<Suspense>` で囲む必要があります。
この講座では第4回からログイン情報を Cookie で扱うので、**仕組みを1つずつ学べるように無効にしておきます**。Cache Components は発展課題として扱います。

## よくあるつまずき

| 症状 | 原因 | 対処 |
|---|---|---|
| `npx create-next-app` が「Node.js のバージョンが古い」と言う | Node.js が 20.9 未満 | Node.js の LTS 版を入れ直す |
| `Port 3000 is in use` | 別のアプリが 3000 番を使っている | そのアプリを止める。第5回の Google ログインは 3000 番前提なので、3001 番で続けない |
| ボタンが青くならない | `globals.css` の書き換え漏れ | 上の差分の `--primary` の行を確認 |
| `Module not found: Can't resolve '@/components/ui/button'` | shadcn の部品を追加していない | 2-1 の `add` コマンドを実行 |
